Promoções

Desconto automático no PDV, na loja toda ou em categorias, dentro do período escolhido. Se duas promoções valem para o mesmo produto, vale a de maior desconto. Ligar uma promoção pede a senha do gerente.

    Notificações de venda

    Avisa este aparelho quando uma venda é concluída em outro aparelho conectado à sincronização, mesmo com o app fechado. Precisa ser ativado em cada aparelho.

    Sincronização na nuvem

    Mantém os dados iguais no PC e no celular, pelo seu Cloudflare (Worker + banco D1). Alterações feitas em aparelhos diferentes são juntadas automaticamente. O endereço e a senha ficam salvos só neste aparelho (fora do GitHub e do backup).

    Backup dos dados

    Os dados ficam salvos neste navegador (e na nuvem, se a sincronização estiver ligada). Baixe um backup com frequência: ele inclui estoque, histórico e financeiro.

    Senha do gerente

    Usada para alterar preços, editar movimentações e excluir produtos. É uma trava de operação, não uma senha de segurança: ela fica salva junto com os dados deste navegador e no arquivo de backup.
    Mínimo de 4 caracteres.

    Modo Faz-de-Conta

    Para testar vendas, entradas e saídas sem medo (modo sandbox). Com ele ligado, nada é salvo, sincronizado ou notificado; ao desligar, os dados voltam a ser exatamente os de antes.

    Financeiro (em pausa)

    O módulo de faturamento MEI saiu da navegação principal enquanto não está em uso. Os dados continuam salvos e entram no backup.
