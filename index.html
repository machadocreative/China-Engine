Backup dos dados

Os dados ficam salvos só neste navegador. Baixe um backup com frequência: ele inclui estoque, histórico e financeiro.

Categorias de produtos

Crie, renomeie ou remova categorias. Renomear move os produtos para o novo nome; só é possível remover categorias sem produtos.

    Senha do gerente

    Usada para alterar preços, editar movimentações e excluir produtos. É uma trava de operação, não uma senha de segurança: ela fica salva junto com os dados deste navegador e no arquivo de backup.
    Mínimo de 4 caracteres.

    Consulta por código de barras
